📖 GUIA DEFINITIVO: Configuração de Alertas do Telegram
Este documento detalha os passos exatos para ativar as notificações do sistema (Motor de Bingo) diretamente para o aplicativo do Telegram do administrador.

ETAPA 1: Criar o Bot e Obter o BOT_TOKEN
O Token é a "chave de acesso" que o Python usa para controlar o seu robô.

Abra o Telegram e pesquise por @BotFather (o que tem o selo azul de verificação).

Envie o comando /newbot.

Digite um Nome amigável para o bot (Ex: Alertas Sistema Bingo).

Digite um Username único, que obrigatoriamente deve terminar com a palavra bot (Ex: SistemaBingo_bot).

O BotFather enviará uma mensagem de sucesso contendo o seu Token da API (um código longo parecido com 8607377804:AAG...).

No Banco de Dados: Abra a coleção parametros, localize o campo token_telegram e cole este código exato (cuidado para não copiar espaços em branco).

ETAPA 2: Autorizar a Comunicação (PASSO CRÍTICO)
Por medida de segurança, o Telegram não permite que bots enviem mensagens para pessoas que não iniciaram a conversa primeiro.

Na barra de pesquisa do Telegram, procure pelo Username do bot que você acabou de criar na Etapa 1.

Abra a conversa com ele e clique em Iniciar (ou envie a palavra Teste).

Não pule este passo! Sem isso, a Etapa 3 não funcionará e o sistema retornará erro Unauthorized.

ETAPA 3: Descobrir o CHAT_ID
O Chat ID diz ao sistema para qual "janela de conversa" a mensagem deve ser enviada. Como bots de terceiros falham frequentemente, usaremos o nosso próprio script de leitura.

Certifique-se de ter feito a Etapa 2 (ter enviado uma mensagem ao bot).

Abra o arquivo descobrir_id.py localizado na pasta raiz do projeto.

Edite a variável TOKEN dentro do arquivo, colando o mesmo código que você pegou na Etapa 1.

Execute o script no terminal:
python descobrir_id.py

O script lerá a caixa de entrada do bot e imprimirá o seu número na tela (Ex: 🎯 O SEU CHAT_ID É: 8374012769).

No Banco de Dados: Abra a coleção parametros, localize o campo chat_id_telegram e cole este número.

💾 BACKUP DO SCRIPT (descobrir_id.py)
Caso o arquivo original seja perdido, crie um arquivo chamado descobrir_id.py e cole o código abaixo:

Python
import requests

# 1. Coloque o token do BotFather aqui:
TOKEN = "SEU_TOKEN_AQUI"
url = f"https://api.telegram.org/bot{TOKEN}/getUpdates"

print("A procurar mensagens na caixa de entrada do bot...")

try:
    resposta = requests.get(url).json()
    
    if resposta.get("ok") and len(resposta.get("result", [])) > 0:
        for item in resposta["result"]:
            if "message" in item:
                chat_id = item["message"]["chat"]["id"]
                nome = item["message"]["chat"].get("first_name", "Utilizador")
                texto = item["message"].get("text", "")
                
                print(f"\n✅ SUCESSO!")
                print(f"👤 Quem enviou: {nome}")
                print(f"💬 Mensagem lida: '{texto}'")
                print(f"🎯 O SEU CHAT_ID É: {chat_id}\n")
                break
    else:
        print("\n❌ A caixa de entrada está vazia.")
        print("Envie uma mensagem (ex: 'Teste') para o SEU bot no Telegram e rode este script novamente.\n")
        
except Exception as e:
    print(f"\n❌ Erro de ligação: {e}")
